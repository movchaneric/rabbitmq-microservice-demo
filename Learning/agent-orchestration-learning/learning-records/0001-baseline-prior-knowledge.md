# Baseline: new to git worktrees and Claude Code subagents

Established 2026-08-06 via direct question. The user has never used git worktrees or
Claude Code's subagent/Task tooling, even informally — despite being comfortable enough
with Claude Code day to day to run three other hands-on learning tracks in this same repo
(RabbitMQ, Redis, gateway, CI/CD). This means Lesson 1 needs to start at true fundamentals
for both primitives (what a worktree actually is on disk, what delegating to a subagent
does to context) rather than skipping straight to composing them. Prior git/TypeScript/
Express fluency from the other tracks transfers, but the multi-agent mechanics themselves
are net new — don't assume familiarity just because the user is an experienced Claude Code
user in the single-agent sense.
